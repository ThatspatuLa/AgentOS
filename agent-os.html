Token Tracking

Usage, costs, context limits, and model breakdown

Input tokens — the words/context you send to the model (your messages, system prompt, file contents). 1 token ≈ 4 characters of English text.
Output tokens — the words the model generates in response.
K = thousand (1K = 1,000). M = million (1M = 1,000,000). Example: 98M = 98,000,000 tokens.
Calls — number of model invocations (each call = 1 prompt + 1 response).
Context limit — max tokens a model can process in one call (input + output). Shown as used / limit with % bar.
FREE = model is on OpenRouter free tier or local. Cost column shows FREE instead of $ amount.

# KCOS Stage 2 live checkpoint

This snapshot records the current live Stage 2 implementation outside Git, together with its direct supervisor integration, related tests and contracts, and installed Hermes Stage 2 shims. `manifest.json` records the SHA-256 and byte length for every captured source file.

The Stage 2 project itself is not a Git worktree. This checkpoint is an archival copy inside ZenNew. It omits changing cycle/runtime evidence, MT5 data and binaries, logs, credentials, historical backups, and unrelated files. It does not change the live Stage 2 files or running scheduler jobs.
